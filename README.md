# Wanderlust 🌍

### A Full-Stack Travel Accommodation Listing Platform

Wanderlust is a full-stack web application inspired by travel accommodation platforms. It allows users to explore accommodation listings, create and manage their own listings, upload images, and share reviews.

The project demonstrates full-stack web development using JavaScript, Node.js, Express.js, and MongoDB.

## ✨ Features

- **Browse Listings:** Explore available travel accommodations.
- **Create and Manage Listings:** Add new properties and manage existing listings.
- **Image Uploads:** Upload listing images using Cloudinary.
- **User Authentication:** Register, log in, and access protected functionality.
- **Reviews:** Add and delete reviews for listings.
- **Location Mapping:** Display property locations using Mapbox.
- **Responsive Interface:** Browse the application on different screen sizes.

## ⚙️ Getting Started

### Prerequisites

Install the following before running the application:

- Node.js and npm
- MongoDB, or a MongoDB Atlas connection
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Vishal-R194/major-project.git
cd major-project
```

### 2. Install dependencies

```bash
npm install
```

If the project has separate frontend and backend directories, install dependencies in the appropriate directories as specified by their `package.json` files.

### 3. Configure environment variables

Create a `.env` file in the directory where the application expects its environment variables.

Configure the variables required by your implementation, such as:

- MongoDB connection string
- Session secret
- Cloudinary credentials
- Mapbox public access token

Use the exact variable names expected by your source code. Never commit real credentials or secrets to GitHub.

### 4. Start the application

Run the start command configured in your `package.json`, for example:

```bash
npm start
```

Check the project's scripts to confirm the correct command before running it.
